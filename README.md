# HTTP-сервис с ограничением нагрузки

HTTP-сервис на Go, который имитирует обработку запросов внешней системой. Сервис ограничивает частоту запросов, возвращает разные статусы и собирает потокобезопасную статистику.

Проект создан во время курса по Go и SQL в техношколе Wildberries. Курс пройден полностью. После курса проект переработан: код разделён на сервер и генератор нагрузки, исправлены гонки данных, добавлены тесты и корректное завершение процесса.

## Возможности

- `POST /requests` — имитация обработки запроса;
- `GET /stats` — статистика по кодам ответа в JSON;
- `GET /health` — проверка доступности;
- ограничение нагрузки через token bucket;
- конкурентная отправка запросов несколькими клиентами и воркерами;
- graceful shutdown по `SIGINT` и `SIGTERM`;
- unit-тесты обработчиков через `httptest`.

У разрешённых запросов вероятность успешного ответа составляет 70%. Запросы сверх лимита получают `429`.

## Запуск

```bash
cp .env.example .env
go run ./cmd/server
```

В другом терминале:

```bash
go run ./cmd/loadtest -clients 2 -workers 2 -requests 100 -rate 5
```

Статистика доступна по адресу `http://localhost:8080/stats`.

## Проверка

```bash
go test -race ./...
```

## Docker

```bash
docker build -t go-rate-limited-service .
docker run --rm -p 8080:8080 --env REQUESTS_PER_SECOND=5 go-rate-limited-service
```

## Структура

```text
cmd/server/       запуск HTTP-сервера
cmd/loadtest/     конкурентный генератор нагрузки
internal/api/     обработчики, ограничение нагрузки и статистика
```

## Стек

Go, `net/http`, goroutines, `sync`, rate limiting, JSON, unit-тесты, Docker.
